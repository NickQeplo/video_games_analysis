# Анализ данных о видеоиграх (2000–2013)

## Описание проекта

В рамках проекта был проведён анализ датасета с информацией о видеоиграх, выпущенных на различных платформах.

Основная цель исследования — подготовить данные к анализу и определить платформы, на которых было выпущено наибольшее количество игр в период с 2000 по 2013 год.

---

## Цель исследования

Определить топ-7 платформ по количеству выпущенных игр за период с 2000 по 2013 год включительно.

---

## Используемые данные

Датасет содержит информацию о видеоиграх:

* название игры;
* игровая платформа;
* год выпуска;
* жанр;
* продажи по регионам;
* оценки пользователей;
* оценки критиков;
* возрастной рейтинг.

Исходный датасет содержал 16 956 записей.

---

## Этапы работы

### 1. Первичный анализ данных

Была изучена структура датасета:

* количество строк и столбцов;
* типы данных;
* наличие пропусков;
* распределение значений по столбцам.

---

### 2. Предобработка данных

В ходе подготовки данных были выполнены следующие действия:

* названия столбцов приведены к формату `snake_case`;
* исправлены неявные дубликаты в столбце жанров;
* удалены явные дубликаты;
* изменены типы данных для повышения удобства анализа;
* обработаны пропущенные значения.

Для заполнения пропусков использовались:

* медианные значения по платформе и году выпуска для региональных продаж;
* средние значения по жанру для оценок пользователей и критиков.

После очистки данных было удалено 515 строк, что составляет около 3% исходного датасета.

---

### 3. Формирование исследуемой выборки

Для дальнейшего анализа был создан отдельный срез данных, содержащий игры, выпущенные в период с 2000 по 2013 год.

Размер итоговой выборки составил 12 778 записей.

---

### 4. Создание дополнительных признаков

Для дальнейшего анализа были созданы новые категории:

#### Категории по оценкам пользователей

* низкая оценка;
* средняя оценка;
* высокая оценка.

#### Категории по оценкам критиков

* низкая оценка;
* средняя оценка;
* высокая оценка.

---

### 5. Анализ платформ

После подготовки данных был проведён анализ количества выпущенных игр по платформам.

На основе полученных результатов был сформирован рейтинг платформ по числу выпущенных игр за рассматриваемый период.
